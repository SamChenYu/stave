# Example scores

Public-domain music, for trying stave out. The files come from these sources, under their licences.

| File | Piece | Source |
|---|---|---|
| `beethoven-op18no1-mvt1.mxl` | Beethoven, String Quartet op. 18 no. 1, I (4 staves, long) | [music21 corpus](https://github.com/cuthbertLab/music21/tree/master/music21/corpus/beethoven/opus18no1) |
| `joplin-maple-leaf-rag.mxl` | Joplin, Maple Leaf Rag (piano) | [music21 corpus](https://github.com/cuthbertLab/music21/tree/master/music21/corpus/joplin) |
| `bach-bwv66-6.mxl` | Bach, chorale BWV 66.6 (4 voices) | [music21 corpus](https://github.com/cuthbertLab/music21/tree/master/music21/corpus/bach) |
| `chopin-prelude.musicxml` | Chopin, a Prelude excerpt (piano) | [W3C MusicXML tutorial](https://github.com/w3c/musicxml/tree/gh-pages/docs/src/data/examples/musicxml) |
| `faure-apres-un-reve.musicxml` | Fauré, Après un rêve (voice and piano) | [W3C MusicXML tutorial](https://github.com/w3c/musicxml/tree/gh-pages/docs/src/data/examples/musicxml) |
